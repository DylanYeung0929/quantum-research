## 1. **概述**

 本研究针对空气质量四分类问题，基于多维环境监测数据（包括PM2.5、PM10、温湿度等9项特征），分别构建了经典神经网络和量子机器学习模型。通过对比分析两种模型在准确率、平均F1分数、运行时间、参数量上的表现，验证了量子计算在环境数据分类任务中的优势。实验数据包含4000条训练样本和1000条测试样本，所有模型参数量严格控制在200以内，最终量子模型以124个参数实现了95.3%的准确率，优于经典模型1.60%。

## **3. 经典神经网络模型**

### **3.1 算法原理**

1. 在本题中，我们选取了传统的多层感知机来设计建构经典神经网络。 MLP 是一种基础的前馈人工神经网络模型，下文码展示了一个用于空气质量预测的双层 MLP 实现。该网络由输入层、隐藏层和输出层构成，核心结构遵循"全连接层+激活函数"的经典设计范式。在初始化阶段，模型通过 Linear 类建立输入层到隐藏层（fc1）和隐藏层到输出层（fc2）的两个线性变换，其中隐藏层维度可由参数灵活指定。特别值得注意的是，该网络采用 ReLU 激活函数替代传统的 Sigmoid 或 Tanh 函数，这种设计能有效缓解深层网络的梯度消失问题，同时提供稀疏表达能力。

![[Pasted image 20250510193522.png]]
									图：MLP 模式流程图

2. 前向传播过程（forward方法）体现了 MLP 的层级特性：输入数据先经过 fc1 的线性变换，再通过 ReLU 的非线性激活，最后经 fc2 输出预测结果。这种"线性变换+非线性激活"的堆叠结构，使网络能够拟合复杂的非线性关系。对于空气质量预测任务，输入维度对应九种各类污染物的监测指标（如PM2.5、SO2等），输出层则对应了分类数（此问题中为四分类）。该模型虽然结构简单，但已具备解决非线性回归问题的基本能力。在实际应用中，可以通过增加隐藏层数量、引入批归一化或调整隐藏单元数等方法来提升模型性能。这种基础架构也为后续扩展更复杂的网络结构（如加入注意力机制）提供了可扩展的框架基础。

```python
class AirQualityNN(Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(AirQualityNN, self).__init__()
        self.fc1 = Linear(input_dim, hidden_dim) # Input layer to hidden layer
        # Change activation function to ReLu
        self.relu = ReLu()
        self.fc2 = Linear(hidden_dim, output_dim) # Hidden layer to output layer
    def forward(self, x):
        # Define forward pass path
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x
```

## **4. 量子机器学习模型**

### **4.1 算法原理**

在本题中，我们设计了参数化量子电路（PQC），该架构创新性地融合了经典数据编码与量子可训练参数，通过量子测量期望值实现特征提取。整个量子线路采用三层级联设计，分别为编码层、变分层、测量层（经典-量子线路结构如图）：
1. **量子特征编码层**：通过RY门实现角度编码，角度编码利用旋转门（RY门）将特征值编码为旋转角度，将经典数据映射到量子态，每个数据点通过单量子比特旋转门精确编码，保持特征空间的拓扑结构。
2. **变分量子处理层**：其中拆分为纠缠层和参数层。
	- **纠缠层**：纠缠层使用CNOT门创建了量子纠缠，通过在4个量子比特之间重复应用CNOT门，将每个量子比特依次连接，形成一个环状结构，从而实现全局纠缠。通过全局纠缠门，可以将复杂的量子线路简化，使所有量子比特协同工作，从而显著提高量子算法的效率，减少量子门的数量和操作时间。在此项目中，制备四量子比特最大纠缠态时，传统方法需要至少三步操作，而使用全局纠缠门仅需一步即可完成，极大地简化了量子线路的设计。
	- **参数层**：参数层使用RY门，对每个量子比特施加独立可调的θ参数，作用类似于神经网络中的“全连接层”，负责引入可调参数用作可训练参数（量子神经网络中的“权重”），对每一层进行可训练旋转操作，- 通过变分优化自动调整量子态空间分布，在训练中调节这些角度以最小化损失函数。
3. **量子测量层**：利用泡利Z门测量一个比特在 Z 方向的期望值，输出范围[-1,1]表征量子态的极化特性，将这些期望值作为量子层的输出特征，交给后续经典网络处理。
